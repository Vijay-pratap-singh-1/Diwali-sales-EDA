# Diwali Sales Analysis (EDA)

## 📌 Project Overview
Diwali is one of the biggest shopping seasons in India, with massive spikes in e-commerce and retail sales.  
This project analyzes a Diwali sales dataset to **identify key customer segments** and **high-performing products**, helping businesses optimize marketing campaigns, inventory, and festive strategies.

**Problem Statement:**  
> Identify the ideal Diwali customer and key product categories to guide business decisions.

---

## 🛠 Tools & Technologies
- **Python:** Pandas, NumPy for data cleaning and analysis  
- **Data Visualization:** Matplotlib, Seaborn  
- **Excel:** Pivot tables, charts, and slicers for ad-hoc analysis  

---

## 📊 Dataset
- **Size:** 30,000+ sales records  
- **Key Features:**  
  - Customer demographics: Age, Gender, Marital Status, Occupation, State  
  - Transaction details: Product Category, Product Name, Amount, Order Count  

---

## 🔍 Analysis & Methodology
1. **Data Cleaning:**  
   - Removed unnecessary columns and missing values  
   - Corrected data types and formatted the `Amount` field  

2. **Exploratory Data Analysis (EDA):**  
   - Gender Analysis: Female customers dominated sales  
   - Age Analysis: 26–35 age group contributed most to sales  
   - Marital Status: Married women were the highest spenders  
   - Occupation: Highest spenders were from IT, Healthcare, and Aviation  
   - Geographic Trends: Top-performing states were UP, Maharashtra, and Karnataka  
   - Product Categories: Food, Clothing, and Electronics dominated purchases  

3. **Visualization:**  
   - Charts and plots to showcase trends and patterns  
   - Pivot tables in Excel for summary statistics  

---

## 🎯 Key Insights
- Ideal Diwali customer: Married woman, 26–35, from UP/Maharashtra/Karnataka, working in IT/Healthcare/Aviation  
- Businesses should focus on targeted ads, regional campaigns, and inventory planning for Food, Clothing, and Electronics
